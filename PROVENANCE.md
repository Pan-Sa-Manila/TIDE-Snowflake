## Models (via Snowflake Cortex)

All models are invoked through Snowflake Cortex inside the account; no external AI endpoints.

| Purpose | Cortex Feature | Model | Constant |
|---|---|---|---|
| Text (structured output) | `AI_COMPLETE` | `openai-gpt-5-mini` | `MODEL_TEXT` |
| Vision (proof analysis) | `AI_COMPLETE`, multimodal via `TO_FILE` | `gemini-2.5-flash` | `MODEL_VISION` |
| Agent orchestration | Cortex Agent (`DATA_AGENT_RUN`) | `auto` (Cortex-selected) | `MODEL_AGENT` |
| Policy retrieval | Cortex Search | N/A (embedding-based) | — |
| Data queries | Cortex Analyst (semantic view) | N/A (Cortex-managed) | — |

Model names are **read from `DECISION.RULE_CONSTANTS` at runtime and never hardcoded**, so the
values above are what those constants hold as of 5 Aug 2026 rather than literals in the source.
Changing a model is a row update, not a code change.
